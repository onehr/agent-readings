<div class="slide-frame">

  <h2>HuggingGPT uses ChatGPT as a controller that plans tasks, selects Hugging Face expert models, executes subtasks, and summarizes the results.</h2>
  <p class="deck-note">HuggingGPT is an early clean statement of the controller-plus-experts pattern: the hard infrastructure is not one model call, but task graphs, resource dependencies, model routing, execution endpoints, and result integration.</p>

<!-- .slide: class="problem-slide" -->

<div class="slide-frame">
  <p class="deck-kicker">Before this paper</p>
  <h2>The friction was structural.</h2>
  <div class="apple-card-grid apple-card-grid--three">
    <div class="apple-card"><p>LLMs such as ChatGPT were strong at text reasoning and interaction but could not directly process many vision, audio, video, or specialized ML tasks.</p></div>
<div class="apple-card"><p>ML communities such as Hugging Face hosted many expert models, but those models did not autonomously coordinate to solve complex user requests.</p></div>
<div class="apple-card"><p>Complex multimodal requests often decompose into ordered subtasks with dependencies across generated resources.</p></div>
  </div>
  <div class="deck-callout">
    <span>Key gap</span>
    <p>The paper asks whether an LLM can serve as the controller that plans, routes, executes, and summarizes across many expert models using language descriptions as the shared interface.</p>
  </div>
</div>

<!-- .slide: class="takeaway-slide" -->

<div class="slide-frame">
  <p class="deck-kicker">Agent infrastructure</p>
  <h2>What changes if you build systems.</h2>
  <div class="apple-card-grid apple-card-grid--two">
    <div class="apple-card"><p>A model-routing agent needs a typed task graph, not just a chat transcript.</p></div>
<div class="apple-card"><p>Resource handles are the minimal runtime abstraction for passing generated artifacts between model calls.</p></div>
<div class="apple-card"><p>Model descriptions are API documentation for model selection; they need curation, ranking, compression, and freshness checks.</p></div>
<div class="apple-card"><p>The controller/expert split makes endpoint health, latency, local fallback, and parallel execution core infrastructure concerns.</p></div>
  </div>
</div>
