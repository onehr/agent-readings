Autonomous Agents Survey

Why It Matters

For agent infrastructure, this is a clear pre-runtime map. Each module implies state management, prompt/schema control, tool execution, evaluation hooks, and failure modes.

Problem

  • Traditional autonomous agents were often trained with limited knowledge in isolated environments.
  • LLMs made open-domain autonomous agents plausible, but early systems were proposed independently with inconsistent terminology.
  • Research on profiles, memory, planning, tools, and evaluation was fragmented across many agent papers.
  • The field needed a taxonomy that connected construction choices to applications and evaluation.

Key gap: The survey asks how to systematically summarize LLM-based autonomous agent construction, applications, evaluation strategies, and challenges.

Method

Survey LLM autonomous agents through three linked taxonomies: construction, applications, and evaluation, with challenges derived from the gaps in those categories.

  • Define the scope around LLM-based autonomous agents rather than general chat models.
  • Propose a unified construction framework with profile, memory, planning, and action modules.
  • Survey memory structures, formats, and operations, including short/long-term memory and database-like stores.
  • Survey planning methods with and without feedback, including external planners and ReAct-style environment feedback.
  • Survey capability acquisition through fine-tuning, prompt engineering, and mechanism engineering.
  • Classify applications in social science, natural science, and engineering.
  • Classify evaluation into subjective and objective strategies and summarize unresolved challenges.

Agent Infrastructure Takeaways

  • This survey gives a clean architecture checklist for reviewing agent papers: profile, memory, planning, action, capability acquisition, and evaluation.
  • Memory formats matter operationally. Natural-language, embedding, database, and structured-list stores expose different retrieval, audit, and mutation semantics.
  • Planning with feedback is the critical line between static prompt decomposition and real agent control loops.
  • Profiles should be treated as configuration with provenance, not harmless prompt text, especially in multi-agent simulations.
  • Evaluation needs subjective and objective signals, but neither is sufficient alone for production-grade confidence.
  • The construction taxonomy is directly useful for this project's review database because it separates mechanisms that Markdown-only summaries tend to blur.

Caveats

  • The arXiv paper has later revisions; this review preserves the reading-list year while noting the source is actively maintained.
  • As a survey, it synthesizes primary papers rather than producing new experimental results.
  • The taxonomy predates many later agent-runtime, safety, and benchmark papers.
  • The application survey includes early-stage prototypes and research demonstrations, so maturity varies widely.
