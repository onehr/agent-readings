Multiagent Debate

Multiagent Debate improves some reasoning and factuality tasks by making several model instances critique and update each other's answers before taking a final consensus.

Why It Matters

It is an important calibration paper for multi-agent systems because it gives a concrete inference-time coordination protocol, direct baselines against single-agent reflection and majority vote, and clear cost/context-length caveats.

Problem

  • Most prompting improvements focused on a single model instance: chain-of-thought, reflection, verification, or self-consistency.
  • Single-agent generations can hallucinate facts or make reasoning jumps while still reporting high confidence.
  • Majority voting can exploit sample diversity, but does not let samples critique each other's reasoning.
  • Multi-agent agent systems needed empirical evidence for when communication adds value beyond simply sampling more answers.

Key gap: The paper asks whether black-box LLM instances can improve factuality and reasoning by communicating before the final answer, rather than only being sampled independently.

Method

Run several black-box LLM instances in parallel, give each one the task, feed each agent the other agents' answers with a debate prompt, repeat for a fixed number of rounds, then use consensus or majority over the final answers.

  • Select a task and a base language model.
  • Instantiate multiple agents, typically copies of the same model.
  • Ask each agent to produce an independent initial answer.
  • For every round, concatenate or summarize the other agents' responses and give them to each agent with a consensus prompt.
  • Ask each agent to update its answer after inspecting the other responses.
  • Stop after the configured number of rounds or when consensus is reached.
  • Evaluate final answers against task-specific labels, factual bullets, Stockfish scores, or chess validity constraints.

Claims

C1 · paper-supported

The debate protocol is model-agnostic and only needs black-box access to generated text.

Scope: Abstract, Introduction, and Section 2.1.

  • E-black-box-method: The paper describes multiple model instances generating candidate answers, reading and critiquing other agents' responses, and updating their own answers over multiple rounds, while requiring only black-box generation access.

C2 · paper-supported

Consensus is empirical rather than guaranteed; when agents do not converge, the paper takes a majority answer.

Scope: Section 2.2.

  • E-consensus: The authors state that convergence is not guaranteed in general, but empirically agents often converge; in remaining disagreement cases they take the majority answer.

C3 · paper-supported

With three agents and two rounds, debate outperforms single-agent, reflection, and majority baselines on the paper's arithmetic, GSM8K, and chess-move optimality reasoning tasks.

Scope: Section 3.1, Table 1.

  • E-reasoning-table: With three agents and two rounds, debate reports 81.8% arithmetic, 85.0% GSM8K, and 122.9 pawn-score chess optimality, versus single-agent 67.0%, 77.0%, and 91.4, reflection 72.1%, 75.0%, and 102.1, and majority 75.0%, 81.0%, and 105.2.

C4 · paper-supported

Debate also improves the paper's factuality evaluations for biographies, MMLU, and chess move validity.

Scope: Section 3.2, Table 2.

  • E-factuality-table: Debate reports 73.8 biography factuality, 71.1 MMLU, and 45.2 chess move validity, versus single-agent 66.0, 63.9, and 29.3; reflection 68.3, 57.7, and 38.8; and majority 67.0 MMLU and 36.0 chess validity.

C5 · paper-supported

The paper's ablations suggest more agents and more rounds can improve arithmetic performance, and different personas can improve MMLU.

Scope: Section 3.3.

  • E-agent-round-analysis: On arithmetic, performance increases monotonically in the reported analysis as the number of debating agents increases and as the number of debate rounds increases.
  • E-persona-analysis: Using different persona prompts on MMLU improves debate performance from 71.1 to 74.2 in the reported experiment.

C6 · paper-supported

Context growth is a real systems constraint for debate, so summarizing other agents' responses is proposed as an efficiency strategy.

Scope: Section 3.3 and Limitations.

  • E-summarization: The paper notes that concatenating all other agents' responses is expensive as agent count grows, and reports that summarizing other responses before debate improves arithmetic performance.
  • E-limitations: The limitations section states that the approach is more expensive than other prompting techniques because it requires multiple agents and debate, and that longer debates strain current models' ability to process context.

C7 · paper-supported

Multiagent Debate is a useful inference-time reliability technique, but it is expensive and can converge to an incorrect answer.

Scope: Introduction, Section 2.2, Appendix qualitative examples, and Limitations.

  • E-limitations: The limitations section states that the approach is more expensive than other prompting techniques because it requires multiple agents and debate, and that longer debates strain current models' ability to process context.
  • E-wrong-consensus: The appendix says debate generally improves final answers, though sometimes answers converge to an incorrect value; Figure 8 also notes that convergence on an uncertain fact is not necessarily correct.

Agent Infrastructure Takeaways

  • Do not count agents; count independent evidence. Debate helps when agents expose different reasoning paths or uncertain facts.
  • Multi-agent communication is not a verifier. Without an external checker, agents can converge on the wrong answer together.
  • The protocol is inference-time reliability through redundancy, critique, and aggregation; the runtime cost scales with agents, rounds, and context size.
  • Debate transcripts are valuable state. They reveal disagreement, persuasion, convergence, and failure modes that a single final answer hides.
  • Summarization is a systems primitive for agent collectives: once every agent must read every other agent, context management becomes the bottleneck.
  • Specialized agents are plausible, but the paper's strongest evidence is still task-local; role design needs measurement, not vibes.

Caveats

  • The README framing is right to be skeptical: some gains are debate-specific, but the method is also an expensive way to use more samples and more tokens.
  • The main reported results use chatGPT-3.5-era models and relatively small evaluated subsets for several tasks.
  • The biography factuality evaluation uses an LLM critic and may miss generated inaccuracies outside the ground-truth bullet list.
  • Consensus is not correctness; the paper explicitly notes that convergence can land on an incorrect value.
  • Long debates create context-length and attention problems, making this as much an inference-systems question as an agent-design question.
  • The method is easiest to evaluate on tasks with extractable final answers; open-ended agent trajectories need stronger instrumentation.
