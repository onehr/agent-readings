# Proof-of-Concepts

Each PoC is local-only and self-contained under `pocs/<paper-slug>/`.

A PoC README must include:

- the paper and exact claim or result it reproduces
- prerequisites
- one command to run it locally
- expected output
- pinned dependencies inside that PoC directory

No PoC should require a network service, deployment target, shared global environment, or credentials.
